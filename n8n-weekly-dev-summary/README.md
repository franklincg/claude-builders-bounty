# Weekly GitHub Dev Summary

1. Import `weekly-dev-summary-workflow.json` into n8n.
2. Set `repo`, `language` (`EN`/`FR`) and Discord webhook in **Config**.
3. Set `GITHUB_TOKEN` and `ANTHROPIC_API_KEY` in the n8n environment.
4. Execute once and verify GitHub → Claude → Discord succeeds.
5. Activate the workflow; it runs Friday at 17:00.
